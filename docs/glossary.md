# 術語對照表

翻譯時以這張表為準；遇到表裡沒有的術語，翻好後補進來（依分區排列）。
中文用台灣慣用譯名；日文用 G検定／JDLA シラバス的寫法；英文是括號裡顯示的寫法（小寫，專有名詞除外）。
